About Us

Welcome to WanderWise ;)

This project is based on building a web application using the Google Maps API's, including the Distance Matrix API, Directions API, Maps JavaScript API, and Places API. The primary goal of the application is to calculate and display the distance and duration between a user-defined origin and destination.
It provides features like searching for nearby places, calculating distances, Google Street View to view famous Locations and more.

Our Mission

Our mission is to help users explore the world with ease by providing a seamless mapping experience and fostering a deeper understanding of how mapping technologies work.
