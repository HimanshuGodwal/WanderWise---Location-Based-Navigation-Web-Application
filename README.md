# WanderWise

Smart Paths for Curious Minds.

A travel companion web application built using Google Maps APIs that helps users calculate routes, explore nearby places, and view detailed location information in real time.

---

# Features

## Route Calculation
- Calculate driving routes between origin and destination
- Display travel distance and estimated driving time

## Nearby Place Search
Search nearby:
- Restaurants
- Cafes
- Hospitals
- Stationery Stores
- Clubs
- Hostels
- Temples

## Place Details Panel
Displays:
- Address
- Contact Number
- Ratings
- Website
- Opening Hours

## Google Places Autocomplete
Autocomplete suggestions for faster and easier location input.

## Responsive Design
Works on:
- Desktop
- Tablets
- Mobile devices

# How It Works

## Step 1 — Enter Locations

Enter:
- Origin
- Destination

Then click:

```bash
Calculate Route
```

The application will:
- Generate route on map
- Show distance
- Show estimated travel time

---

## Step 2 — Explore Nearby Places

Use category buttons to search nearby places around the current map location.

Example:
- Restaurants
- Cafes
- Hospitals
- Temples

Markers will appear on the map.

---

## Step 3 — View Place Details

Click any marker to view:
- Address
- Phone Number
- Ratings
- Website
- Opening Hours

inside the side panel.

# Installation

## 1. Clone Repository

```bash
git clone https://github.com/your-username/wanderwise.git
```

---

## 2. Open Project Folder

```bash
cd wanderwise
```

---

## 3. Add Google Maps API Key

Inside `index.html` replace:

```html
YOUR_API_KEY
```

with your actual Google Maps API key.

---

## 4. Run Project

Simply open:

```bash
index.html
```

in your browser.
